# qu-n-l-qu-n-cafe--
Dự án xây dựng hệ thống quản lý toàn bộ hoạt động tại quán cà phê: quản lý thông tin nhân viên, lịch làm việc, chấm công, tính lương; quản lý thực đơn, đơn hàng, kho hàng, nhà cung cấp; theo dõi doanh thu, chi phí và tạo báo cáo thống kê. Giúp vận hành hiệu quả, giảm sai sót và dễ dàng theo dõi mọi hoạt động kinh doanh.
